# NYPD Shooting Incident Data Analysis

## Overview
This project analyzes NYPD shooting incident data from NYC Open Data to identify patterns in gun violence across New York City from 2019 onward.

The analysis focuses on shooting trends by borough, time, season, victim demographics, and fatality rates.

## Tools & Technologies
- Python
- Pandas
- Matplotlib & Seaborn
- SciPy
- Socrata API
- Jupyter Notebook

## Analysis
Using Python and Pandas, we cleaned and analyzed 5,000+ NYPD shooting records and created visualizations to examine:

- Shooting incidents by borough
- Yearly and seasonal trends
- Most common times and days
- Victim age groups
- Fatal vs. non-fatal shootings

We also used Pearson correlation, chi-square testing, and seasonal analysis to examine patterns in the data.

## Key Findings
- Brooklyn and the Bronx had the most shooting incidents.
- Shootings increased sharply in 2020 and declined afterward.
- Incidents were more common during summer months.
- Most shootings occurred between 9 PM and 4 AM.
- Fatality rates varied across boroughs.
